# 09 — Lista polimórfica: folha de pagamento

**Use quando:** precisar somar resultados calculados de maneiras diferentes

**O que adaptar:** Funcionario/Fixo/Comissionado e salário/comissão.

## Executar

Abra o terminal nesta pasta e execute:

```sh
javac -encoding UTF-8 -d out Main.java
java -cp out template09.Main
```

## Resultado / roteiro de teste

Mostra salários 2000.0 e 500.0; total 2500.0; média 1250.0. Valores de exemplo presumem salários, vendas e taxa válidos.

As classes auxiliares estão no mesmo arquivo para facilitar a consulta. Se o enunciado exigir arquivos separados, mova cada classe para seu próprio arquivo, mantenha o mesmo `package` e adicione `public` à classe. Compile todos com `javac -encoding UTF-8 -d out *.java`.
