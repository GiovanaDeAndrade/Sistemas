# Sistemas de Informação — FURB

Repositório de exercícios, avaliações e projetos em Java da graduação em Sistemas de Informação na Universidade Regional de Blumenau.

- **Introdução à Programação** — lógica, estruturas de repetição, vetores e matrizes. O trabalho final foi um jogo de Liga 4.
- **Programação Orientada a Objetos** — atividades sobre classes, encapsulamento, herança e polimorfismo.
