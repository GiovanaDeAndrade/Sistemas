# Programação Orientada a Objetos — 2026.2

Projeto Java organizado para uso no Eclipse com os exemplos registrados no Notion da disciplina.

## Conteúdo

- `com.example.projeto01`: classes, objetos, atributos e métodos (`Carro`, `Cachorro` e `App`).
- `com.example.ExemploEncapsulamento`: encapsulamento, getters/setters, depósito e saque (`ContaBancaria` e `App`).

## Eclipse

No Eclipse, use **File > Import > Existing Projects into Workspace** e selecione a pasta `ProgramacaoOrientadaObjetos`.
