# Semestre 02 — Unidade 01

Atividades de Programação Orientada a Objetos organizadas em uma única estrutura para o repositório `Sistemas`.

## Atividades

- `Atividade01` — introdução a classes e objetos (`Carro`, `Cachorro` e `Rodar`).
- `Atividade02` — **Hello Git**, atividade do GitHub Classroom. O programa imprime `Hello Git!` no terminal.
- `Atividade03` — **Retângulo Simples**, com a classe `Retangulo`, atributos privados, construtor, getters, setters, cálculo de área e perímetro e uma classe `App` para demonstração.

## Organização

Os exercícios do GitHub Classroom ficam aqui como arquivos Java normais, e não como repositórios Git aninhados. Isso evita o problema de o GitHub mostrar uma pasta como `gitlink`/submódulo sem exibir os arquivos do exercício.

O código foi ajustado somente no `package` para seguir a estrutura do projeto principal:

```text
Semestre02.Unidade01.AtividadeXX
```
